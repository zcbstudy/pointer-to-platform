demo17_lseek 学习笔记

==================================================
一、学习目标
==================================================

lseek() 不负责读数据，也不负责写数据。
它只负责主动调整当前文件描述符对应的文件偏移量。

后续的 read() 或 write() 会从这个偏移位置开始操作。


==================================================
二、函数声明
==================================================

off_t lseek(int fd, off_t offset, int whence);

需要头文件：

#include <unistd.h>


==================================================
三、参数含义
==================================================

fd：
要操作的文件描述符，必须来自成功的 open()。

offset：
相对于基准位置移动多少字节。
正数表示向后移动，0 表示不移动，负数表示向前移动。

whence：
指定从哪个基准位置计算。

SEEK_SET：
从文件开头计算。

SEEK_CUR：
从当前偏移位置计算。

SEEK_END：
从文件末尾计算。


==================================================
四、计算方式
==================================================

SEEK_SET：

新偏移量 = offset

示例：

lseek(fd, 3, SEEK_SET);

表示移动到距离文件开头 3 字节的位置。


SEEK_CUR：

新偏移量 = 当前偏移量 + offset

示例：

lseek(fd, 2, SEEK_CUR);

表示从当前位置再向后移动 2 字节。


SEEK_END：

新偏移量 = 文件大小 + offset

示例：

lseek(fd, -2, SEEK_END);

表示从文件末尾向前移动 2 字节。


==================================================
五、返回值
==================================================

返回类型：

off_t

off_t 是表示文件偏移量的有符号整数类型。

返回规则：

成功：
返回调整后的新偏移量。

失败：
返回 -1。


查询当前位置：

off_t pos;

pos = lseek(fd, 0, SEEK_CUR);

这里 offset 为 0，所以不会移动，只返回当前位置。


==================================================
六、文件偏移量如何变化
==================================================

普通文件刚 open() 成功后，初始偏移量通常为 0。

read() 成功后：

文件偏移量 += 实际读取字节数

write() 成功后：

文件偏移量 += 实际写入字节数


假设文件内容：

abcdefg

位置可以理解为：

0 a 1 b 2 c 3 d 4 e 5 f 6 g 7


执行：

re = read(fd, buf, 2);

读取到：

ab

此时偏移量自动变成 2：

ab|cdefg


==================================================
七、lseek() 与 read() 的组合
==================================================

假设当前偏移量为 2。

执行：

lseek(fd, 2, SEEK_CUR);

新位置：

2 + 2 = 4

此时：

abcd|efg

后续 read() 会从 e 开始读取。


执行：

lseek(fd, 0, SEEK_SET);

会重新回到文件开头。

后续 read() 会重新从 a 开始读取。


==================================================
八、lseek() 与 write() 的组合
==================================================

假设文件内容：

abcdefg

先执行：

re = read(fd, buf, 2);

此时：

ab|cdefg

如果直接执行：

write(fd, "XY", 2);

结果：

abXYefg

因为 write() 从当前位置开始覆盖 c 和 d。


如果先执行：

lseek(fd, 2, SEEK_CUR);

此时：

abcd|efg

再执行：

write(fd, "XY", 2);

结果：

abcdXYg

因为 e 和 f 被覆盖。


==================================================
九、覆盖不是插入
==================================================

普通文件中的 write() 会从当前偏移位置开始覆盖原来的字节。

它不会自动把后面的内容整体向后移动。


原文件：

abcdefg

当前位置：

ab|cdefg

执行：

write(fd, "XY", 2);

结果：

abXYefg


不会自动得到：

abXYcdefg


真正的中间插入通常需要：

1. 保存插入点后面的原内容
2. 写入新内容
3. 再把原内容接到后面

因此：

lseek() 只能决定从哪里操作，
不能自动实现文件中间插入。


==================================================
十、O_APPEND 的影响
==================================================

如果文件这样打开：

open("a.txt", O_RDWR | O_APPEND);

那么每次 write() 都会强制写到文件末尾。

即使前面用 lseek() 把偏移量移到文件中间，
普通 write() 仍会追加到末尾。

但是 lseek() 调整的位置仍然会影响 read()。


==================================================
十一、常用写法
==================================================

回到文件开头：

lseek(fd, 0, SEEK_SET);


查询当前位置：

lseek(fd, 0, SEEK_CUR);


移动到文件末尾：

lseek(fd, 0, SEEK_END);


从当前位置向后移动 2 字节：

lseek(fd, 2, SEEK_CUR);


从当前位置向前移动 2 字节：

lseek(fd, -2, SEEK_CUR);


从文件末尾向前移动 5 字节：

lseek(fd, -5, SEEK_END);


==================================================
十二、当前阶段总结
==================================================

lseek()：
只负责调整文件偏移量。

read()：
从当前偏移位置读取，并自动推进偏移量。

write()：
从当前偏移位置覆盖写入，并自动推进偏移量。

SEEK_SET：
从文件开头计算。

SEEK_CUR：
从当前位置计算。

SEEK_END：
从文件末尾计算。

lseek(fd, 0, SEEK_CUR)：
查询当前位置。

write()：
默认是覆盖，不是中间插入。

O_APPEND：
强制每次 write() 写到文件末尾。
