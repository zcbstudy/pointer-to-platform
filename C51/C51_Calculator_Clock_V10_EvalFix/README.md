# V10 Lite — Calculator + Clock

C51 V10 EvalFix 使用说明
==========================

这是 AT89C51 + 6位共阳数码管 + 74HC138 + 4x4键盘 的计算器/电子时钟精简版。
只保留一个 main.c，不需要任何自定义 .h 文件。
已用 D:\KEIL\C51\BIN\C51.EXE 和 BL51.EXE 实际编译/链接通过，采用 OPTIMIZE(9,SIZE) RAMSIZE(128)。
编译结果：code=2005字节，data=97.5字节，0 errors，0 warnings。HEX 已生成。
注意：这不等于 Proteus 仿真通过。

文件：
Source/main.c            完整源代码
HEX/V10_EvalFix.hex      可直接加载到 Proteus 里的 HEX
Keil/V10_EvalFix.uvproj  尝试供 Keil uVision4 打开；CLI 真实验证过，不代表本工程的 GUI 构建已经验证

电路连线（沿用教材）：
P0.0~P0.7 -> 数码管a,b,c,d,e,f,g,dp，每段应有限流电阻；
P1.0/1/2 -> 74HC138 A/B/C，P1.3 -> G1（高有效），P1.4 -> /G2A（低有效），/G2B -> GND；
74HC138 Y0~Y5 -> PNP基极电阻 -> 六个位选，PNP发射极接+5V、集电极接共阳端；
P2.0~P2.3 -> 4行键盘输出，P2.4~P2.7 -> 4列键盘输入；
P3.2 -> 新增BUTTON，另一端接地，短按切换计算器/时钟。
EA（31脚）需可靠接+5V，晶振设为11.0592MHz，晶振两侧电容推荐22~33pF。
P0为开漏口，实际电路须考虑上拉和驱动能力，不可直接承受过大LED电流。

按键：
计算器模式：0~9输入六位非负整数；A加，B减，C乘，D除；Enter等于；ESC清零。
结果：正数0~999999；负数幅值最多99999（留一位显示负号）；除法只显示整数商。
非法输入/溢出/除零：六位显示EEEEEE，ESC恢复。
时钟模式：显示HH.MM.SS；A加1小时，B加1分钟，C秒归零；所有时钟计时在计算器模式中也继续运行。
P3.2：短按在时钟与计算器模式间切换。

特别说明：
uVision4工程配置基于原V9复制，并设为 AT89C51 + 优化9（SIZE）。
最可靠的已验证结果是本目录提供的 HEX；如果 GUI 里F7报L250，请对照源文件和 C51 编译优化选项。
