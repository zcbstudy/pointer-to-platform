# C51 V10 — 旧版 Proteus 蜂鸣器低电平驱动修复

基于此前同一版 AT89C51 V10 源码改动，不重写结构，不改硬件引脚：

- `P1.6` 经10k电阻接PNP基极；低电平导通、持续供电，有源蜂鸣器发声；高电平关闭。
- `Timer0` 每1ms倒计时；`Timer1` 取消，不再产生方波。
- 仍保留六位数加减乘除（整数除法）、24小时电子时钟、P3.2模式切换、P3.3 HHMMSS校时、数码管 `LedBuff[5-i]` 位序。
- 整点报时200ms，计算器错误报警150ms，其他按键静音。
- 已在用户电脑上 Keil C51 v9.02 Eval 下编译验证：0错误/0警告，code=2023字节，data=62.6字节；Eval限制使用0x061C/0x0800；Intel HEX最高地址`0x0FE0`，不超出AT89C51的4KB Flash。
- 当前尚未在用户 Proteus 电路中做整机仿真验证。该方式适用于旧仿真中的直流驱动 BUZZER 器件，不适用于需要音频方波驱动的纯无源压电片。
