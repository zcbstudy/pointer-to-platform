# AT89C52 教材计算器 + 软件电子时钟 V9

这是将教材第8.5节《简易加法计算器》作为主要代码骨架而制作的简化版。包含独立 .c 模块，只有一个 main()；没有自行创建的 .h。本 GitHub 目录中的源码已转换成 UTF-8，方便网页查看中文注释；用户电脑本地 Keil µVision4 工程中的原始代码仍使用 GBK。

## 与教材对应
- KeyCodeMap[4][4]：键值表，保留教材的十六进制键值
- KeySta[4][4]：稳定按键状态（0按下，1松开）
- KeyScan()：每1ms扫描矩阵键盘当前一行，连续4次一致判稳
- KeyDriver()：在主循环中读取一次按下事件
- KeyAction()：处理数字和四则运算操作
- ShowNumber()：把数字写入数码管缓存
- LedChar[] / LedBuff[8]：数码管段码/显示缓存
- LedScan()：定时器中断调用的显示扫描
- InterruptTimer0()：Timer0中断

## 具体功能
1. 计算器：两个0~99的整数做加减乘除，除法显示整数商。结果在-99~99时支持继续参与下一次运算；结果范围更大时不能继续连算，按数字可重新开始。错误时显示Err并蜂鸣。输入第三位或除0报警。
2. 电子时钟：12:00:00启动，24小时制、按键校时、整点蜂鸣器报时；8x8点阵固定显示钟面。
3. LED：状态指示+流水灯；蜂鸣器：短按提示音、错误长鸣、整点报时。
4. **不包含**：之前的秒表和倒计时，按当前用户“教材计算器为基础，加一个模拟时钟”的简化方向处理。

## 按键映射（键盘实物通常印有A/B/C/D/*/#）

| 实物按键 | 教材 KeyCodeMap 键码 | 计算器 | 电子时钟 |
|---|---|---|---|
| 0~9 | 0x30~0x39 | 输入数字 | 无作用 |
| A | 0x26 | 加法 | 小时加1 |
| B | 0x25 | 减法 | 分钟加1 |
| C | 0x28 | 乘法 | 秒清零 |
| D | 0x27 | 除法 | 报时开/关 |
| # | 0x0D | 等号 | 无作用 |
| * 短按 | 0x1B | 清零/解除错误 | 无作用 |
| * 长按1秒 | 0x80 | 切换到时钟 | 切换到计算器 |

## 代码文件

| 文件 | 作用 |
|---|---|
| main.c | 唯一主入口；切换功能，调用 KeyDriver/KeyAction |
| key.c | 教材式KeyScan、KeyDriver、KeySta、KeyCodeMap |
| calculator.c | 教材式KeyAction扩展为加减乘除 |
| segment.c | LedChar/LedBuff/ShowNumber/LedScan |

## Keil uVision4 打开步骤
1. 整包解压至英文路径，例如 `D:\C51_Textbook_Calculator_Clock_V9\`。
2. 打开 `Keil\C51_Textbook_Calculator_Clock_V9.uvproj`。
3. 按F7编译，确认0 errors、0 warnings且生成HEX。
4. V9改写了多个模块，**没有在本环境完成Keil原生编译和Proteus电气仿真**；必须以你的电脑实际结果为准。

## 硬件条件（必须确认）
- 软件暂按AT89C52传统12T、12MHz晶振设计。
- P1.0~P1.3键盘行，P1.4~P1.7键盘列。
- P0低电平有效的8位段选/点阵列数据；P2低电平有效的8位选择信号。
- P3.0蜂鸣器、P3.1~P3.5 LED、P3.6数码管组使能、P3.7点阵组使能。
- 数码管共阳，点阵行阳列阴是尚待核实的**假设**。显示组选择必须有电气隔离及限流/供电驱动电路，不能仅将所有LED裸接到P0和P2。
- P0没有内部上拉，必须按实际驱动电路处理；也需核算AT89C52端口电流。
